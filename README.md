# Idle RPG

Idle RPG с автобоем для **Telegram Mini App** по ТЗ «Легион Валькирий»: отряд из пяти героинь сам сражается с волнами
врагов и боссами, фармит золото, опыт и снаряжение даже офлайн; игрок собирает Легион, прокачивает героинь,
одевает их и принимает стратегические решения. Название игры — **Idle RPG**, лор «Легиона Валькирий» сохранён внутри мира.

- 8 классов, 60 героинь (R / SR / SSR / UR, включая 10 освобождённых владычиц и 5 Вестниц), коллекции обликов «Лето», «Будуар» и «Маскарад»;
- древо навыков на каждый класс (3 ветки × 10 узлов, ярусы, модификаторы, ключевые таланты), специализации, пробуждение UR;
- 10 актов × 20 этапов × 3 сложности, 60 врагов, 30 мини-боссов, 10 боссов актов с уникальными механиками;
- 11 слотов снаряжения, 7 редкостей, 32 аффикса, 30 сетов (4 из них — только из режимов), 37 легендарок, мифические эффекты, камни, заточка, перековка, кузница;
- idle-сундук (12–24 ч), 2 бесплатных быстрых сбора в день, бесплатное ускорение ×2, «Пока вас не было»;
- режимы: экспедиции, 5 подземелий (одно — «подземелье дня» ×1.5), Башня (500 этажей, модификаторы этажей и «Испытание»), Арена, Лабиринт, Бездна, Разлом Колосса (тактики), Стихийные шпили, Нашествие (благословения);
- созвездие аккаунта (240 звёзд), Вознесение (Эфир, 50 рангов улучшений), сюжет по циклам;
- ежедневные/еженедельные задания, календарь входа на 28 дней, достижения с титулами, боевой пропуск;
- без доната и рекламы (личная игра): облики продаются за кристаллы, всё открывается игрой; рефералы и рейтинги под флагом;
- удобства: «Забрать всё» в заданиях и экспедициях, «Зачистить все» подземелья, сортировка героинь, полный сброс прогресса в «Настройках»;
- режим разработчика по белому списку Telegram ID (раздел 16 ТЗ);
- RU / EN (английский словарь подгружается по требованию), пиксельный стиль, звук и музыка (синтез WebAudio).

## Архитектура

```
packages/shared   @idle/shared  — общий детерминированный движок: контент, формулы, симулятор боя, все действия игрока
apps/client       @idle/client  — Mini App: Vite + React 19 + Zustand + PixiJS 8, CSS-модули
apps/server       @idle/server  — NestJS 11 + PostgreSQL + Redis (опц.) + grammY (бот, уведомления)
```

**Сервер — источник истины.** Каждое действие игрока (`{type, ...params}`) применяется функцией `applyAction` из
`@idle/shared`. Клиент применяет его оптимистично и параллельно отправляет на `/api/action`; сервер применяет то же
действие со своим временем и ГПСЧ из состояния, отвечает хешем состояния, клиент сверяет хеш и при расхождении
перезагружает состояние. Сиды боёв выдаёт сервер, офлайн-доход считается по серверному времени, платёжные действия
выполняются только сервером (`trusted`), все изменения валют пишутся в `ledger`.

Бой — шкала ходов по SPD, энергия и ультимейты, статусы, ~40 спецэффектов, 10 механик боссов. Один и тот же
симулятор визуализируется на клиенте (PixiJS) и пересчитывается на сервере в «тихом» режиме.

Графика процедурная: спрайты героинь и врагов 32×32 собираются из слоёв (силуэт класса, волосы, одежда, оружие,
палитра), иконки 16×16 — из ASCII-шаблонов, фоны актов — параллакс из 4 слоёв. Никаких внешних ассетов: первая
загрузка ≈ 0,7 МБ (JS/CSS ≈ 0,4 МБ gzip + шрифты), вкладки грузятся лениво.

## Быстрый старт (без сервера)

```bash
npm ci
npm run build:shared
npm run dev:client            # http://localhost:5173/?local
```

В локальном режиме игра целиком работает в браузере (сохранение в `localStorage`, dev-панель доступна).
Это удобно для разработки контента и баланса.

## Полный стек локально

```bash
docker compose up -d db redis        # PostgreSQL 16 и Redis
cp .env.example .env                 # заполнить; для локалки: ALLOW_INSECURE_AUTH=true, BOT_MODE=off
npm run dev:server                   # API на :3000 (миграции применяются автоматически)
VITE_REMOTE=1 npm run dev:client     # клиент ходит в /api через прокси Vite
```

`ALLOW_INSECURE_AUTH=true` разрешает вход без Telegram (пользователь `dev-local`) — **только для разработки**.

## Подключение к Telegram

1. **@BotFather** → `/newbot` → получите `BOT_TOKEN`, запишите `BOT_USERNAME`.
2. `/newapp` → выберите бота, укажите https-адрес клиента (`WEBAPP_URL`) и короткое имя (`APP_NAME`) — ссылки
   вида `t.me/<bot>/<app>?startapp=ref_<id>` используются для рефералов.
3. `/mybots` → Bot Settings → Menu Button → тот же URL (кнопка «Играть» в чате).
4. На сервере: `BOT_MODE=webhook`, `WEBHOOK_URL=https://<домен>` (сервер сам зарегистрирует
   `https://<домен>/api/bot/webhook`), `WEBHOOK_SECRET=<случайная строка>`.

Для отладки бота без публичного адреса — `BOT_MODE=polling` (long polling снимает вебхук у бота!).
`BOT_MODE=off` — бот не принимает обновления, но уведомления отправлять может.

**Бот:** `/start` присылает картинку `welcome.png` (`scripts/welcome-banner.ts`) с описанием игры
и кнопками «Играть», «Как играть», «🌐 Язык · Language», «Что нового», «Сообщить о баге»; `/help` — краткая инструкция;
`/news` (или `/changelog`) — последние обновления игры (из `packages/shared/src/content/changelog.ts`);
`/lang` — язык бота (русский / English; хранится в таблице `bot_users`, важнее языка Telegram, по нему же
приходят уведомления, меню команд чата переключается на выбранный язык); `/clear` — очистить чат: бот удаляет
недавнюю переписку (Telegram разрешает это для сообщений младше 48 ч) и заново присылает приветствие, прогресс
игры не трогается; `/bug <текст>` — баг-репорт прямо из чата.

**Блокнот идей (только для разработчиков из `DEV_USER_IDS`):** `/idea` — бот просит описать идею и сохраняет
следующее сообщение (или сразу `/idea текст`; ждёт 30 минут, `/cancel` — отменить); `/ideas` — последние идеи
с кнопками удаления «🗑 #N», «📄 Выгрузить все» (файл `ideas-ДАТА.md`) и «🧹 Удалить все» с подтверждением.
Идеи хранятся в таблице `ideas`, ожидание ответа — в `bot_pending` (serverless: без состояния в памяти).
Команды блокнота видны в меню только в чате разработчика. Для чтения из диалога с ассистентом — админ-API:

```bash
curl -H "X-Admin-Token: $ADMIN_TOKEN" "https://<домен>/api/admin/ideas?format=md"   # или без format — JSON
curl -X POST -H "X-Admin-Token: $ADMIN_TOKEN" -H 'Content-Type: application/json' -d '{"text":"…"}' https://<домен>/api/admin/ideas
curl -X DELETE -H "X-Admin-Token: $ADMIN_TOKEN" https://<домен>/api/admin/ideas/12
```

Меню команд обновляется при настройке бота
(`POST /api/admin/bot/setup`, см. «Деплой на Vercel»).

**Баг-репорты:** кнопка в «Настройках» (текст + по желанию данные устройства, текущий экран и последние
ошибки клиента) → `POST /api/bug-report` → сообщение в личку от бота. Получатели — `BUG_REPORT_CHAT_ID`
(Telegram ID через запятую), а если пусто — разработчики из `DEV_USER_IDS`. Отчёты также сохраняются в
таблицу `bug_reports`; лимит — 15 в день на игрока. Чтобы бот мог написать вам, один раз нажмите у него `/start`.

## Деплой (Docker)

```bash
cp .env.example .env      # BOT_TOKEN, WEBAPP_URL, WEBHOOK_URL, SESSION_SECRET, DEV_USER_IDS …
docker compose up -d --build
```

Образ содержит API, собранный клиент (раздаётся тем же сервером как SPA) и бота. Перед контейнером нужен
HTTPS-прокси (Caddy / nginx / Cloudflare Tunnel): Telegram открывает Mini App и шлёт вебхуки только по https.
Проверка: `GET /api/health`.

Все переменные описаны в [`.env.example`](.env.example).

## Деплой на Vercel

Проект уже настроен для Vercel ([`vercel.json`](vercel.json)): клиент раздаётся CDN как статика,
всё API (NestJS) работает одной функцией [`api/index.js`](api/index.js) в регионе `fra1`, база — Neon Postgres
из Vercel Marketplace (переменная `DATABASE_URL` появляется при подключении базы к проекту).

На Vercel сервер сам включает **serverless-режим** (`VERCEL=1` → `SERVERLESS=true`):
- состояние игрока не кэшируется в памяти: каждое действие выполняется в транзакции с блокировкой строки
  (`SELECT … FOR UPDATE`), сохраняется до ответа, повторы по action id отсекаются таблицей `action_results`;
- ledger пишется в той же транзакции, аналитика и фоновые задачи — через `waitUntil` после ответа;
- уведомления «сундук полон» запускает Vercel Cron (`GET /api/cron/notify`, раз в день на тарифе Hobby,
  защищён `CRON_SECRET`);
- вебхук бота не ставится при каждом холодном старте — его регистрирует один запрос после деплоя:

```bash
curl -X POST -H "X-Admin-Token: $ADMIN_TOKEN" https://<домен>/api/admin/bot/setup
# → setWebhook(<WEBHOOK_URL>/api/bot/webhook), команды бота и кнопка меню «Играть» (WEBAPP_URL)
```

Переменные проекта: `DATABASE_URL` (от Neon), `BOT_TOKEN`, `BOT_USERNAME`, `WEBAPP_URL` и `WEBHOOK_URL`
(= адрес проекта), `BOT_MODE=webhook`, `WEBHOOK_SECRET`, `SESSION_SECRET`, `ADMIN_TOKEN`, `CRON_SECRET`,
при необходимости `DEV_MODE_ENABLED`, `DEV_USER_IDS` и `BUG_REPORT_CHAT_ID`. После изменения переменных нужен повторный деплой.

```bash
npx vercel deploy --prod      # из корня репозитория; сборка идёт на стороне Vercel
```

## Режим разработчика

- `DEV_MODE_ENABLED=true` и `DEV_USER_IDS=<ваш Telegram ID>` — после входа в «Настройках» появится
  «Режим разработчика». Каждый dev-запрос повторно проверяется на сервере; `DEV_MODE_ENABLED=false` отключает всё.
- Возможности: выдача/списание любых валют (×1K, ×1M, «Макс.», «Обнулить»), героини (уровень, звёзды,
  специализация, облик, всё древо), конструктор предметов и полные сеты, переход на любой этап/сложность/этаж,
  перемотка времени (+1 ч, +12 ч, +7 дней), сброс дневных лимитов, бессмертие, убийство с одного удара,
  скорость ×5/×10, лог урона с раскладкой формулы, фиксированный seed, горячая перезагрузка баланса,
  3 слота снимков состояния, полный сброс.
- Каждое dev-действие пишется в журнал (`dev_log`).

## Баланс

Все коэффициенты — в [`packages/shared/src/config/balance.json`](packages/shared/src/config/balance.json).
На сервере можно указать `BALANCE_CONFIG_PATH`: файл перечитывается при изменении (частичный JSON сливается
поверх базового), клиенты получают актуальную версию при входе. Ручная перезагрузка — `POST /api/admin/config/reload`
(заголовок `X-Admin-Token`) или из dev-панели.

Симулятор F2P-игрока (5 сессий в день, разумная стратегия: задания, призыв, прокачка, заточка, режимы, экспедиции,
арена, Вознесение при упоре в потолок):

```bash
npm run balance -- 90 5                            # дней, сессий в день
CFG='{"gear":{"growthLate":1.07}}' npm run balance  # проверить правку без изменения файла
```

Формулы ТЗ соблюдены буквально: `XP(L) = 100·L^2.2`, `HP = HP0·1.09^n`, `ATK = ATK0·1.08^n`, боссы ×8 HP / ×1,5 ATK,
таймер 60 с, Hard ×25, Nightmare ×400, `Ether = ⌊10·(Stage/50)^1.6⌋`. Решения, принятые при балансировке:

- **Уровень силы этапа.** Номер `n` в формуле врагов — сквозной внутри сложности (1–200), множитель сложности
  применяется сверху: Hard 1-1 ≈ Normal 2-18, Normal 10-20 = 200, Hard 10-20 ≈ 237, Nightmare 10-20 ≈ 270.
  Иначе переход Normal → Hard был бы обрывом ×25 после уже экспоненциального роста.
- **Уровень и звёзды героини усиливают и базу, и снаряжение** (`(База·Редкость + Экипировка)·(1+0,08(L−1))·(1+0,15(S−1))`).
  По формуле ТЗ буквально прокачка героини к середине игры переставала бы влиять на силу.
- **Кривая снаряжения ускоряется с уровнем** (`growth` → `growthLate` за `growthRamp` уровней): в начале силу даёт
  прокачка, ближе к концу — лут.
- **«Память Легиона»:** каждый цикл Вознесения умножает ATK/HP отряда на `1 + cyclePower`.
- При переполнении инвентаря переплавляется самый слабый свободный предмет, а не новый; «Надеть лучшее»
  переносит заточку на более сильный предмет (за обычную цену переноса).

Результат симулятора на текущем `balance.json` (200 дней, 5 сессий в день):

| Веха | Симулятор | Ориентир ТЗ |
|---|---|---|
| Акт 1 пройден | ~4 часа | день 1 |
| Акт 5 пройден | ~6 день | ~неделя 3 |
| Normal 10-20 | ~83 день | ~месяц 2 |
| Hard 10-20 | ~124 день | — |
| Nightmare 10-20 | ~163 день | 6–9 месяцев |
| Первое Вознесение / далее | ~9 день / каждые ~6 дней | 3–4 недели / 5–10 дней |
| Кристаллы F2P | ~2,5 тыс./нед. в фазе прогресса, ~1,3 тыс./нед. дальше | ~1 500/нед. |

Начало игры быстрее ориентира: ранние этапы проходятся за счёт дешёвых уровней, а стены возникают на боссах актов
5–8. Кривую можно подвинуть параметрами `gear.growth*`, `income.*`, `enemy.actBossMult`, `ascension.cyclePower`
без изменения кода.

## Что реализовано иначе или не полностью

- **Арт** — процедурный пиксель-арт без рисованных атласов (открытый вопрос ТЗ про художника остаётся):
  фигуры 48×48 собирает `apps/client/src/art/figure.ts`, фоны мест — `scenes.ts`, иконки — `icons.ts` и `itemArt.ts`.
  Инструменты: `scripts/figure-preview.ts` (лист героинь/врагов), `scripts/skin-diff.ts` (насколько облик отличается
  от обычного вида), `scripts/items-preview.ts`, `scripts/welcome-banner.ts` (картинка `/start`).
- **Шрифт** — Handjet (тонкий пиксельный с кириллицей) вместо Pixelify Sans: у последнего нечитаемая кириллица.
- **Облики** — кроме классических, коллекции «Лето» (20 купальников) и «Будуар» (20 комплектов белья, без наготы).
  8 из них — эксклюзив магазина за кристаллы; остальные также добываются: боевой пропуск (4 облика за сезон,
  пул ротируется), магазины арены, Лабиринта и ивента, этажи Башни 150/250/350/450.
- **Ручные ульты** (Настройки → «Ручные ульты в боях с боссами», по умолчанию включены): в бою с боссом,
  вызванным игроком, и во всех боях режимов внизу сцены — портреты героинь с кольцом энергии; полное кольцо —
  нажми, и героиня выпустит ульту на своём ходу; «Авто» — до конца боя ульты сами. Как это работает: симулятор
  общий и детерминированный, клиент считает бой локально и при каждой команде пересчитывает его (прошлое не
  меняется), а после боя отправляет действие с командами `{ manual: true, inputs: [{ t, u }] }` — сервер
  повторяет тот же бой. Автоповтор и автобосс идут на авто.
- **Сокрушительный удар** — боссы (каждые 11 с) и мини-боссы (каждые 14 с) заряжают удар по всему отряду
  (42% / 28% макс. HP), над ними видна полоса каста. Ульта по кастующему (или оглушение/заморозка) сбивает удар,
  ультой — ещё и оглушает. Боссы стали заметно сложнее на авто; вовремя выпущенные ульты это компенсируют.
- **Встречи** (с этапа 5) — раз в 15–35 минут на экране боя появляется событие на 20 минут: сундук у дороги
  (добыча или мимик), бродячая торговка, алтарь стихий, раненая путница, игрок в кости, засада разбойниц.
  Каждое — выбор с ценой или риском; бои встреч тоже с ручными ультами.
- **Уход за героинями** (Лагерь → «Уход», только UR) — близость 0–10: разговоры (3 в день, тема и порядок
  ответов детерминированы днём, лучший ответ зависит от характера), угощения (3 в день, у каждой любимое и
  нелюбимое), горячие источники (раз в день, за кристаллы; героиня в купальнике — летний облик или скрытый
  «банный», который нельзя надеть в бою) и свидания (с близости 3, раз в день; любимое место — больше близости).
  Вкусы открываются на близости 2, любимое место — на 4. Каждый уровень даёт +2% HP/атаки/защиты, пики 3/5/7/10 —
  кристаллы, свитки и осколки. **Наряд близости** (юката, вечернее платье или шёлковая пижама — по характеру)
  открывается только на близости 10 и за 10 **Сердец Эфира**: они падают в Разломе (ярус 8+), в Нашествии
  (каждые 25 волн), в испытании Башни (каждый 10-й этаж) и в Стихийных шпилях (каждые 25 этажей).
- **Резиденция** (в «Уходе») — общие комнаты героинь, каждую можно обустроить и улучшить до 5 уровня (золото от
  дохода, с 3-го уровня ещё кристаллы): гостиная (+15% близости от разговоров за уровень), кухня (+15% от угощений),
  ванная (ванна раз в день каждой героине: героиня в купальнике, пена до плеч) и спальня — **ночёвка** с близости 5,
  одна героиня за ночь: пижама (скрытый облик), одеяло, «Zzz», утром подарок — минуты дохода золота и опыта. Только сон,
  без откровенного. В сцене героини можно переключаться между лагерем и обустроенными комнатами. Фоны мест — процедурный
  пиксель-арт 128×100 (`apps/client/src/art/scenes.ts`).
- **Артефакты** (Призыв → вкладка «Артефакты», с этапа 25) — отдельный баннер «Сокровищница Эфира» (200/1800 кристаллов,
  бесплатно раз в день; шансы R 60 / SR 30 / SSR 8.5 / UR 1.5 %, гарант SSR — 30, UR — 90 призывов). 12 механик на весь
  отряд, считаются в общем симуляторе боя (`BattleSetup.artifacts`, сторона игрока): «Тлеющий амулет» (каждый 6-й удар
  поджигает), «Фляга росы» (лечение каждые 10 с), «Боевой барабан» (стартовая энергия), «Колокол тревоги» (щит при <50%),
  «Сердце бури» (ульта даёт энергию остальным), «Метка охотницы», «Громовой колокольчик» (молния каждый 8-й удар),
  «Оберег предчувствия» (щит на каст Сокрушительного удара), «Пепел феникса» (первая павшая возрождается), «Цепь времени»
  (враги ходят позже каждые 15 с), «Рог Валькирии» (лечение и атака при <50% здоровья отряда), «Призма Эфира» (урон за
  разные стихии). Дубликат — уровень до 5, дальше возврат кристаллами. Слоты: 2, с 40-го уровня аккаунта — 3. Числа
  подобраны так, что один артефакт 1-го уровня ≈ +0,5–1 уровень героинь, 5-го — ≈ +1,5–2 (замер на пограничном боссе).
  В бою над целью всплывает иконка и название сработавшего артефакта.
- **Праздники Легиона** (лагерь → баннер праздника или Карта → режимы; с 10-го уровня аккаунта) — большой ивент, который
  идёт всегда, но каждые 14 дней сменяется по кругу: «Кровавая Луна» → «Турнир Валькирий» → «Праздник Приливов» →
  «Самоцветные копи» → «Цветение Сакуры» (`FESTIVAL_EPOCH` — 26.09.2026). У каждого праздника своя UR-героиня (Селена,
  Фрейя, Амфитрита, Рубина, Цубаки — не выпадают в призыве, осколки только за награды праздника) и фон; общие для всех —
  задания дня, цели, шкала очков и лавка. Главная часть зависит от типа праздника (`FestivalDef.kind`):
  - **путь** (`trail`: Луна, Приливы, Сакура) — описан ниже;
  - **турнир** (`tourney`) — драфт: 5 раз выбрать одну из трёх случайных героинь (из всех, не только своих; одного уровня 40,
    без экипировки, дерева, связи, созвездий и артефактов — звёзды по редкости), затем бои с дружинами соперниц до 7 побед
    или 3 поражений; после каждой победы можно заменить одну героиню. Соперницы с раундом сильнее и реже R, 7-й раунд —
    финал с Фрейей. 2 входа в день (+ входы из лавки); за победы — жетоны и очки, за титул — сундук с осколками Фрейи,
    в конце забега — кристаллы по числу побед;
  - **копи** (`mine`) — поле 7×8 в тумане: копать можно только клетку рядом с раскопанной, соседи видны заранее; шаг —
    одна кирка (25 на старте, +25 в день, запас 60, ещё — в лавке). Руда/самоцветы — жетоны, сундук — ресурсы или осколки,
    родник +4 кирки, ловушка −2, чудовище — бой своим отрядом (уровень от фарма, глубже сильнее), лестница — спуск на
    этаж ниже с наградой (каждый 3-й — осколки Рубины и страж у лестницы, каждый 5-й — Сердце Эфира).

  **Путь-праздник**: свой босс-колосс; **путь** из 18 этапов в трёх главах
  (враги из своих актов, условия этапов — модификаторы Башни, стражи глав на 6/12, на 18-м — испытание героини праздника;
  сила врагов считается от уровня фарма на старте праздника и растёт до «фарм +10»; звёзды: все выжили — 3, пала одна — 2;
  первое прохождение бесплатно, повтор — рейд за билет, 5 билетов в день, этапы на 3★ — быстрый рейд);
  **босс** (3 попытки в день, урон копится, после победы — уровень выше, сундук с осколками героини);
  **задания дня** (одно праздничное + три общих), **цели** на весь праздник, **шкала** из 25 наград за очки праздника
  (осколки, предметы, Сердца Эфира, в финале — облик героини праздника) и **лавка** за жетоны ивента (осколки героини,
  облики других героинь, ресурсы; лимиты — на праздник). При входе новый праздник анонсируется один раз.
  Сложность откалибрована симуляцией: отряд на своём рубеже проходит ~12 этапов, дальше нужен рост за праздник.
  **Управление из бота** (только разработчик из `DEV_USER_IDS`): `/fest` — статус, ближайшие праздники и кнопки;
  `/fest start луна 7` — запустить сейчас на 7 дней, `/fest stop`, `/fest plan сакура 25.10 01.11` (можно с временем
  `25.10 18:00`), `/fest end 12.10` — новый конец текущего, `/fest del 2` — убрать запись, `/fest auto` — вернуть ротацию.
  Время — московское. Расписание хранится в `server_settings` (`festival_schedule`), сервер подмешивает его в конфиг
  (`cfg.festival`, перечитывает раз в 15 с), а клиент по версии в ответах на действия (`fest`) сам перезапрашивает конфиг.
  Продление/сокращение идущего праздника сохраняет прогресс игроков; новый праздник — с нуля (номера праздников из бота
  начинаются с 1 000 000 и не пересекаются с ротацией). Без записи в расписании — «Сейчас праздника нет» и дата следующего.
- **Свойства элиты** — с 11-го этапа у боссов этапов кампании (элита и мини-боссы; на Hard/Nightmare — и владычицы)
  появляются свойства: броня, скорость, вампиризм, шипы, ярость, исполин, смертоносность, щит. Normal — одно свойство,
  Hard/Nightmare — два (у владычиц — одно). Свойства показаны на экране боя, каждое даёт +20% золота и опыта за победу.
- **Анимация призыва** (героини и артефакты): магический круг заряжается цветом лучшей редкости → звёзды падают в круг
  (цвет каждой — редкость находки) → вспышка (для UR — радужная волна и тряска) → «прожектор» с силуэтом для SSR/UR →
  карты вылетают из круга и переворачиваются по очереди. Любой этап можно пропустить.
- **Что нового** — список изменений открывается один раз при входе после обновления (`settings.news`),
  его можно перечитать в лагере и в боте (`/news`). Новая запись — в начало `CHANGELOG`: иконка, суть одной фразой,
  цвет, героиня для карточки и только 2–3 главных пункта (мелкие правки и исправления туда не пишем — это проверяет тест).
  В игре последнее обновление — большой карточкой, прошлые — списком, раскрываются по нажатию.
- **Полноэкранный Telegram** — верхняя панель учитывает `--tg-content-safe-area-inset-top` (зону кнопок «✕» и «•••»).
- **Интерактивные режимы**:
  - **Нашествие** — каждые 3 волны выбор одного из трёх благословений (Ярость, Стена щитов, Кровавый пакт,
    Передышка, Жадность и др.): бонусы складываются до конца забега, следующая волна — после выбора;
  - **Башня** — у каждого обычного этажа свой модификатор (Великаны, Бешенство, Эфирная буря…);
    «Испытание ×2»: враги +60% HP и +30% атаки, награда за этаж удвоена;
  - **Разлом** — тактика на каждый бой: Натиск, Бастион или Ритуал;
  - **Подземелья** — «подземелье дня» с наградой ×1.5, кнопка «Зачистить все».
- **Сеты режимов** — «Доспех Колосса» (Разлом, ярус 4+, за победу — мифический), «Знамя Орды» (Нашествие,
  каждые 10 волн), «Стихийная призма» (шпили, каждые 10 этажей), «Наряд арлекина» («Испытание» на этажах
  стражей Башни). Не куются в кузнице. Плюс 9 новых легендарок (Лук лисьего огня, Снежные клыки, Щит гладиатора…).
- **Новенькие** — Зарина (танцовщица-бард), Юки (снежная куноити), Мелюзина (дочь морского дракона, UR),
  Роксана (гладиаторша) и Тамамо (кицунэ-лучница); все в призыве.
- **«Маскарад»** — 15 обликов владычиц и новеньких: новые наряды «кролик» (боди, колготки-сетка, ушки) и
  «горничная» (корсет, фартучек, чулки). Пять — за 25-й этаж Стихийных шпилей (по стихии), три — за рекорды
  Нашествия (волны 20/40/60), остальные — арена, лабиринт, ивент и магазин обликов; все продаются за кристаллы.
- **Полный сброс** — «Настройки → Начать заново»: подтверждение с задержкой 5 с, игра начинается с нуля,
  сохраняются только настройки и имя.
- **Вестницы Эфира и Колоссы** — 5 героинь-Вестниц (по одной на стихию) и 5 Колоссов: крупнее остальных
  (Вестницы ×1,2 в бою, Колоссы ×2,5), парят над землёй, окружены аурой стихии, машут крыльями/хвостом.
  Вестницы не выпадают в призыве — их осколки дают три новых режима.
- **Разлом Колосса** (с этапа 50) — мировой босс дня (пн — Пламя, вт — Глубины, ср — Чаща, чт — Заря,
  пт — Бездна, в выходные по кругу): 3 попытки по 45 с, награда по нанесённому урону (10 ярусов), осколки
  Вестницы стихии дня, быстрая зачистка лучшим ярусом дня.
- **Стихийные шпили** (с этапа 70) — башни на 120 этажей для отряда одной стихии (пять сильнейших героинь);
  в будни открыт шпиль дня, в выходные все; каждые 10 этажей — 10 осколков Вестницы, каждые 30 — Колосс-страж.
- **Нашествие** (с этапа 35) — ежедневный забег на выживание: здоровье переносится между волнами, передышка
  каждые 5 волн, осколки случайной Вестницы каждые 10, Колосс каждые 25; отступить можно в любой момент.
- **Боевой пропуск** — 50 бесплатных уровней с наградой на каждом, облики на 15/30/40/50, «Забрать всё»,
  бесконечные бонусные сундуки после 50-го уровня; повторный облик превращается в 300 кристаллов.
- **Гильдии, рейды, ивенты** — не реализованы (по ТЗ социальный модуль опционален). Есть рейтинги и рефералы под
  флагом `SOCIAL_ENABLED`, магазины арены/Лабиринта, магазин ивента наполнится вместе с ивентами.
- **WebSocket** не используется: арена асинхронная, рейдов нет — хватает REST.
- **Донат и реклама убраны**: игра личная. Вместо рекламы — бесплатные ускорения ×2 (лимит в день), второй
  бесплатный быстрый сбор и ежедневный бесплатный призыв; лимит офлайна 24 ч добирается созвездием.
- **Аналитика** — события пишутся в таблицу `analytics_events` и, при `POSTHOG_KEY`, отправляются в PostHog.
- **Балансовые цели ТЗ** достигнуты приблизительно (см. результаты симулятора выше); все параметры правятся без релиза.
